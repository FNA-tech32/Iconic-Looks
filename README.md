# Iconic Looks

Iconic Looks is a one-page website for a beauty salon. It covers haircuts, color, styling, treatments, and makeup, with a lookbook and a way to book an appointment.

## Sections

- **Home** — headline and a first-visit offer
- **Services** — expert beauticians, salon services, and products
- **About** — a short story and a studio video
- **Stylists** — the salon team
- **Offers** — a color-day discount
- **Lookbook** — a photo grid of finished looks
- **Contact** — address, phone, email, and social links

## Tech

HTML, CSS, and JavaScript. The page is static. Navigation jumps to sections on the same page, and a sidebar menu opens on smaller screens.

## How to open

Open `index.html` in a browser. No install or build step is required.

## Files

- `index.html` — page structure and content
- `style.css` — layout and styling
- `main.js` — sidebar menu
- `reset.css` and `normalize.css` — base styles
- `Assets/` — photos, icons, and the about video
